## Key Findings

### Deduplication Logic Verified
- Exact match: same text + category → duplicate rejected
- Case-insensitive: "User Prefers Dark Mode" == "user prefers dark mode"
- Whitespace-normalized: "  User   prefers  mode " == "User prefers mode"
- Near-except (long texts >20 chars): prefix/suffix variations caught
- Different categories allowed: same text can exist in PREFERENCE and CONTEXT
- Short texts (<20 chars): no prefix matching to avoid false positives

### Persistence Format Verified
- File path: `data/memory/session_<sha256(session_id)[:16]>.json`
- Top-level structure: `{"session_id", "facts", "updated_at"}`
- Fact structure: `{"text", "category", "confidence", "created_at", "last_referenced"}`

### Edge Cases Handled
- Empty/whitespace-only text rejected
- Confidence clamped to [0.0, 1.0]
- Corrupted JSON falls back to empty state
- MAX_FACTS limit enforced with FIFO trimming
