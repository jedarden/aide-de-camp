**Bead:** adc-34h50

## Summary

Completed comprehensive 30-day deployment analysis comparing `pbx-web` and `whisper-stt` services on ardenone-cluster.

## Findings

### Key Result
Both services demonstrated **excellent operational stability** with zero pod restarts, crashes, or availability issues despite 10 deployments each over the analysis period.

### Deployment Patterns
- **pbx-web:** 10 deployments across 3 services (pbx-web, pbx-rebuild-relay, lab-rebuild-relay)
- **whisper-stt:** 10 deployments across 2 services (whisper-stt, whisper-openai)
- Both services averaged 1 deployment every 3 days

### Notable Patterns
- **whisper-stt burst:** July 8 saw 3 deployments within 17 minutes (likely config reload pattern)
- **pbx-web cluster:** July 13 saw 2 deployments within 11 minutes (similar config pattern)
- **Resource profiles:** whisper-stt uses 16x more CPU/RAM (8 CPU, 8Gi vs 500m CPU, 512Mi)

### Shared Characteristics
- Zero restarts across all pods
- 100% availability (ReadyReplicas = DesiredReplicas)
- Healthy ArgoCD sync status
- Both use Reloader operator for config-driven restarts
- No OOM or resource constraints observed
