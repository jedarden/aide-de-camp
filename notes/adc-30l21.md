# Base pbx-web-build Workflow Query

## Finding
**0 pbx-web-build workflows found in iad-ci cluster.**

The `pbx-web-build` WorkflowTemplate exists (confirmed via `kubectl get workflowtemplates`), but no workflow instances have been created from it.

## Correct Base Query

Since Argo Workflows does not automatically apply a `workflows.argoproj.io/workflow-template` label, we must filter by `.spec.workflowTemplateRef.name` using jq:

```bash
kubectl --kubeconfig=/home/coding/.kube/iad-ci.kubeconfig \
  get workflows -n argo-workflows \
  -o json \
  | jq '[.items[] | select(.spec.workflowTemplateRef.name == "pbx-web-build")]'
```

**Key points:**
- Output format: JSON array of workflow objects
- Sorting: Inherited from `kubectl get` (can add `--sort-by=.metadata.creationTimestamp` to the kubectl command)
- Filtering: Done via jq on `spec.workflowTemplateRef.name`, not kubectl labels
- Count: Check with `jq 'length'` on the result
