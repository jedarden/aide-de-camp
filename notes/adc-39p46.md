## Key Findings

### Filtering Method Characteristics

1. **Date Range Calculation:**
   ```python
   now = datetime.now(timezone.utc)
   since = (now - timedelta(days=30)).strftime("%Y-%m-%dT%H:%M:%SZ")
   until = (now + timedelta(days=1)).strftime("%Y-%m-%dT%H:%M:%SZ")
   ```

2. **Boundary Operators:**
   - `since` is **inclusive** (`>=`)
   - `until` is **exclusive** (`<`)
   - Prevents double-counting at boundaries

3. **Timezone Safety:**
   - Both Kubernetes and client use UTC
   - No timezone conversion issues
   - Handles both `Z` suffix and `+/-HH:MM` offset formats
