# Workflow Data Parsing (adc-1y487)

## Task
Parse and extract relevant deployment data from raw workflow JSON.

## Implementation

Created Python parser (`~/scratch/parse-workflows.py`) that extracts the following fields from each workflow:
- **workflow_name**: metadata.name
- **status**: status.phase (success/failure state)
- **started_at**: status.startedAt timestamp
- **finished_at**: status.finishedAt timestamp
- **duration_seconds**: Calculated from start/finish timestamps
- **message**: status.message
- **error_conditions**: List of error messages from workflow and failed nodes
- **success**: Boolean derived from status.phase

## Results

Successfully parsed `pbx-web-raw-workflows.json` → `pbx-web-parsed-deployments.json`

Output structure:
```json
{
  "total_workflows": 0,
  "successful_deployments": 0,
  "failed_deployments": 0,
  "workflows": []
}
```

## Context

The empty result aligns with findings from task adc-55v7b: no pbx-web-build workflow executions were found in the last 30 days. The workflow template exists but has not been used for deployments in the analysis period.

## Deliverables
