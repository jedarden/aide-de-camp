# adc-11773: Workflow Data Parser Implementation

## What Was Done

Created a robust workflow data parser (`parse_workflow_data.py`) that:

1. **Parses Argo Workflow JSON** - Reads WorkflowList format from kubectl
2. **Extracts deployment metrics** for each workflow run:
   - workflow_name
   - namespace
   - workflow_template
   - started_at (ISO 8601 timestamp)
   - finished_at (ISO 8601 timestamp)
   - phase (Succeeded/Failed/Error)
   - message (error message if present)
   - duration_seconds (calculated from timestamps)
   - duration_formatted (human-readable: "30.5s", "5.2m", "2.1h")
   - uid (unique identifier)

3. **Handles missing data gracefully** - None values for unfinished/missing fields
4. **Provides structured output** ready for serialization to JSON

## Results

The raw workflow query (`pbx-web-raw.json`) contained **no workflow runs** in the last 30 days for the `pbx-web-build` template. The parser correctly handled this empty case and produced a structured output with:

- Query metadata preserved
- Empty deployments array
- Explanatory note about no results found
